# Carlink (Paused – Redirecting to Native Version)

**IMPORTANT NOTICE: This project is currently paused.**

Development and updates have moved to the fully native Android version, which offers better performance, no Flutter/Dart dependencies, improved video reliability (especially on GM AAOS head units), and Google Play readiness.

### Please use the new native repository instead:
👉 **https://github.com/MotoInsight/Carlink_native**

The native version includes:
- All core features from this repo
- Enhanced black screen recovery (additional keyframe requests, reset button)
- Optimized for GM Intel-based AAOS 12L/14
- Preparation for Google Play Internal Testing
- Active builds (latest: Build 52)

Thank you for your interest! Head over to the native repo for the latest code, builds, and ongoing development.

---

**Original Project Overview (Archived)**  
This was the Flutter-based Carlink implementation. For historical reference only.

- Enables CarPlay/Android Auto projection via Carlinkit adapters  
- USB protocol handling  
- Video/audio streaming  

All active work has been migrated to the native fork linked above.
